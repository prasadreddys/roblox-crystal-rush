Crystal Rush is a bright 3D arena coin-collector for Roblox: grab gold coins, chase the golden crystal worth 10x, and beat the 120-second clock — solo or with friends.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Open game.rbxl in Roblox Studio and press Play, or publish it as a Public experience.
